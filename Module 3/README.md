# Module 3

This module introduces back-end development using Node.js and Express. The focus is on creating a simple service API that can handle requests, store data in memory, and respond with JSON.

## What students are learning

In this module, students practice:

- setting up a Node.js project
- creating a server with Express
- creating REST API routes
- working with GET, POST, PUT, and DELETE requests
- returning JSON data
- testing an API with VS Code, the terminal, and Postman

## Project folders

### `Course_backend/`
This project is a simple course service API. It includes course data and basic CRUD routes for managing course records.

### `Todo_backend/`
This project is a simple to-do service API. Each item includes a unique ID, description, due date, and whether it is completed.

## How to run the projects

1. Open the project folder in VS Code.
2. In the terminal, run `npm install`.
3. Then run `npm start`.
4. Open `http://localhost:3000` or use Postman to test the endpoints.

## Module goal

The goal of Module 3 is to help students understand how back-end services work, how APIs are structured, and how Node.js with Express can be used to build simple real-world applications.
