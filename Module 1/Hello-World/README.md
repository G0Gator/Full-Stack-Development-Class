# Hello World Practice

This project is the first basic webpage created in the course. It is meant to introduce students to the fundamentals of HTML and CSS and help them understand how a basic website is built from simple elements.

## Project purpose

The goal of this folder is to teach the basics of:

- structuring a webpage with HTML
- linking a CSS file to a page
- styling text and layout
- creating a simple, readable design
- understanding how files work together in a web project

## Files included

- `hello.html` – the main HTML page
- `hello.css` – the stylesheet used to style the content
- `README.md` – project overview

## What this project demonstrates

This project introduces the simplest form of a website: a page with content and styling. Students learn how HTML creates the structure while CSS controls the look of the page.

## How to view the page

1. Open `hello.html` in a browser.
2. If you are using VS Code, you can also open it with Live Server.
3. You can then make changes to the HTML and CSS to see the page update.

## Learning takeaway

This is the first step in front-end development. The goal is to help students become comfortable writing the basic structure of a website before moving into more advanced layouts, interactivity, and design patterns.
