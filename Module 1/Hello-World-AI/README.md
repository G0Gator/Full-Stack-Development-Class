# Hello World AI

This project is a modernized AI-inspired version of the original Hello World webpage. The purpose is to show how a simple beginner project can be transformed into a more polished, visually engaging design while still keeping the same basic learning goals.

## Project purpose

This example helps students see how front-end design can evolve from a very basic page into a more creative layout using:

- modern color schemes
- stronger typography
- card-style sections
- hero sections
- responsive layout techniques
- interactive JavaScript behavior

## Files included

- `index.html` – the main page structure and content
- `styles.css` – the styling for the page design
- `script.js` – JavaScript that adds a simple greeting interaction
- `README.md` – project overview and instructions

## What the page demonstrates

This page includes:

- a modern hero section
- AI-inspired branding and color palette
- design elements like gradients, glow effects, and glass-style panels
- a simple interactive input and greeting button
- responsive design so the layout adjusts well across screen sizes

## How to use it

1. Open `index.html` in a browser.
2. Type your name into the text field.
3. Click the button to see the greeting message.
4. Explore the CSS file to see how the design is built.

## Class idea

This project is useful for showing students how visual design can improve a webpage without changing the learning objective. It is a simple example of how an introductory assignment can become more engaging with smart layout choices and creative styling.
