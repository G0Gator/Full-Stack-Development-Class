# Hello World AI

This project is a more advanced HTML/CSS example for a class demonstration of AI-themed web design.

## Files

- `hello-world-ai.html` – the main page structure
- `hello-world-ai.css` – the styling and layout
- `script.js` – interactive greeting behavior

## What it demonstrates

- Modern page layout
- Hero section design
- AI-inspired color palette and glassmorphism styling
- Responsive layout for different screen sizes
- JavaScript interaction with a name input and greeting message

## How to use

1. Open `hello-world-ai.html` in a browser.
2. Type your name into the input box.
3. Click the button to see the greeting message.

## Class idea

This file can be used as an example of how AI and modern web design can be presented in a simple project while still showing strong visual design and interactivity.
