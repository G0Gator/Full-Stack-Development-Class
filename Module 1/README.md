# Module 1

This folder includes the first set of beginner web development exercises for the course. The focus of this module is learning the building blocks of HTML and CSS and becoming comfortable with simple page layouts, styling, and project structure.

## What students are learning

In this module, students practice:

- creating a basic HTML page
- linking CSS files to pages
- styling text, colors, spacing, and layout
- adding images and media elements
- using responsive design principles
- organizing files inside a project folder
- understanding the basics of source control and version tracking

## Project folders

### `Hello-World/`
This folder contains the first basic webpage created in class. It is a simple example to introduce HTML and CSS structure.

### `Hello-World-AI/`
This is an AI-themed variation of the initial greeting page. It demonstrates how a simple webpage can be styled to look more modern and visually engaging.

### `Sampling-Source-Control/`
This folder focuses on a more complete page that includes media examples such as an image, a video, and a geolocation feature. It also introduces the idea of source control and file tracking.

### `Sampling-Source-Control-AI/`
This version builds on the original sampling page with a cleaner and more polished design, while still keeping the same educational content and purpose.

### `Survey-Form/`
This folder contains a survey form project that demonstrates how to create a polished form using HTML and CSS. It includes multiple question types, required fields, and a simple submission experience.

## How to use these projects

1. Open any project folder.
2. Open the `.html` file in your browser.
3. Review the related CSS file to see how the page is styled.
4. Use the examples to practice editing and customizing the layout.

## Module goal

The goal of Module 1 is to help students get comfortable with the fundamentals of front-end development and begin building a strong foundation for future projects.
