# Sampling and Source Control Practice

This project is a beginner-friendly HTML and CSS assignment designed to practice multiple web development concepts in one page. It introduces the idea of building a simple webpage with different content sections and media examples while also reinforcing the concept of source control and project organization.

## Project purpose

The goal of this project is to help students understand how to:

- build a webpage with multiple content blocks
- add links, images, and video elements
- use CSS to create a responsive layout
- organize files into a project folder
- understand the value of source control when working on a project

## Files included

- `main.html` – the main structure of the page
- `main.css` – the styling for the layout and design
- `Keiran.jpg` – an image used in the page
- `Running.mp4` – a video used in the page
- `README.md` – project overview and instructions

## What the page includes

This page contains four main examples:

1. A link section with a GitHub profile link
2. An image section showing a local image file
3. A video section demonstrating embedded media
4. A geolocation button that requests the user's location

## Responsive behavior

The layout is built to adapt to different screen sizes. The columns change their arrangement depending on the browser width so the page remains readable and usable on smaller screens.

## How to view the project

1. Open `main.html` in a browser.
2. If using VS Code, you can also open it with Live Server.
3. The page will load the local image and video files from the same folder.

## Learning takeaway

This project helps students connect beginner HTML/CSS concepts with real-world web page design and project structure. It also introduces the idea that projects should be organized, tracked, and updated carefully as they grow.
