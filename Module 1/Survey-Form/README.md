# Survey Form

This project is a simple HTML survey form created as part of Module 1. It demonstrates form structure, input fields, radio buttons, checkboxes, required fields, and basic styling with CSS.

## Project purpose

The survey collects information such as:

- name
- email
- grade level
- sports participation
- interest in joining another sport
- comments or personal story

## Files included

- `main.html` – the survey form markup
- `main.css` – page styling and layout

## How to view it

1. Open the `Survey-Form` folder.
2. Open `main.html` in a browser.
3. Or open the file in VS Code and use a live preview extension.

## Skills practiced

- HTML form elements
- CSS layout design
- required form validation
- radio buttons and checkboxes
- clean form styling for a user-friendly interface
