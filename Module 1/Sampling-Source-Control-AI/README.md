# Sampling-Source-Control-AI

This is a cleaner, more polished version of the original sampling and source control webpage.

- a clean responsive layout
- four content cards
- a GitHub link section

## How to view

Open `index.html` in your browser, or preview it with VS Code Live Server.

This page is designed for an intro HTML and CSS class to practice:

- HTML structure

- card layout design
- responsive behavior
- simple JavaScript interactivity
