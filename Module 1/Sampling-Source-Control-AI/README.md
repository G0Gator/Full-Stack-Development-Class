# Sampling-Source-Control-AI

This project is a cleaned-up AI-themed version of the original sampling and source control webpage. It keeps the same educational idea as the original assignment but presents it in a more polished and modern design.

## Project purpose

This page is used to demonstrate how a simple beginner web project can be improved with stronger visual design while still teaching the same core concepts. The assignment focuses on HTML structure, CSS styling, responsive layout behavior, and simple JavaScript interaction.

## Files included

- `index.html` – the main page layout and content
- `styles.css` – the styling and responsive design
- `script.js` – JavaScript for the interactive geolocation button
- `README.md` – project overview and instructions

## What is included on the page

This version includes the same core examples from the original project, but presented in a cleaner card-based layout:

- a GitHub link
- an image example
- a video example
- a geolocation button
- a polished modern visual theme

## Styling approach

The design uses a more refined visual style inspired by clean AI and dashboard aesthetics. It includes:

- a blue and teal color palette
- rounded cards and borders
- softer shadows
- responsive spacing
- consistent typography and layout

## How to view the project

1. Open `index.html` in a browser.
2. Or use Live Server in VS Code to preview the page.
3. Resize the browser window to see how the layout responds on smaller screens.

## Skills being practiced

This project helps students practice:

- semantic HTML layout
- CSS layout design
- responsive web design
- image and video integration
- basic JavaScript for interactivity
- creating a clean and professional beginner website

## Learning takeaway

This project shows how a simple class assignment can become more visually appealing and polished without losing the essential beginner web design learning goals.
