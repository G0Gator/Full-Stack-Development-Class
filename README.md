# Full Stack Development Class

This repository contains the projects and exercises completed during my Full Stack Development class. The work focuses on learning the fundamentals of front-end development, JavaScript, source control, and basic back-end development with Node.js and Express.

## Course focus

This repository was created to practice:

- HTML structure and semantic layout
- CSS styling and page design
- responsive web design
- JavaScript interactivity
- Git and source control basics
- project organization and file structure
- basic Node.js and Express back-end development
- creating simple API services for class exercises

## Repository structure

- `Module 1/` – basic front-end and HTML/CSS exercises
  - `Hello-World/`
  - `Hello-World-AI/`
  - `Sampling-Source-Control/`
  - `Sampling-Source-Control-AI/`
  - `Survey-Form/`

- `Module 2/` – JavaScript logic and API practice
  - `Caesar's-Cipher/`
  - `Central-Tendency-Calculator/`
  - `Palindrome-Checker/`
  - `PokeAPI/`

- `Module 3/` – back-end development with Node.js and Express
  - `Course_backend/`
  - `Todo_backend/`

## How to view projects

1. Open the folder you want to preview.
2. Open the relevant `.html` file in a browser for front-end projects.
3. For back-end projects, open the project folder in VS Code and run `npm start` in the terminal.
4. Use Postman or a browser to test the API endpoints.

## Learning goals

The main goal of this repository is to build confidence with:

- writing clean HTML files
- styling with CSS
- creating simple interactive experiences
- working with JavaScript logic and browser APIs
- understanding version control
- building a basic back-end service with Express
- creating and testing API endpoints for class assignments

## Notes

Each folder is designed as a small learning exercise and shows the progression from basic front-end work into JavaScript logic and simple service-based back-end applications.
