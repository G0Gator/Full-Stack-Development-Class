# Full Stack Development Class

This repository contains the projects and exercises completed during my Full Stack Development class. The work focuses on learning the fundamentals of building websites using HTML, CSS, and basic JavaScript while also exploring responsive design, source control, and AI-inspired web design.

## Course focus

This repository was created to practice:

- HTML structure and semantic layout
- CSS styling and page design
- Responsive web design
- JavaScript interactivity
- Git and source control basics
- Project organization and file structure
- AI-themed design concepts for class examples

## Repository structure

- `Module 1/` – introductory HTML/CSS projects and practice assignments
  - `Hello-World/` – first webpage practice
  - `Hello-World-AI/` – AI-themed version of a simple webpage
  - `Sampling-Source-Control/` – media and layout practice using source control concepts
  - `Sampling-Source-Control-AI/` – cleaned-up AI version of the media project

## How to view projects

1. Open the project folder you want to preview.
2. Open the `index.html` or `.html` file in a browser.
3. If using VS Code, you can also preview with Live Server for a smoother workflow.

## Learning goals

The main goal of this repository is to build confidence with:

- writing clean HTML files
- styling with CSS
- creating simple interactive experiences
- making pages responsive for different screen sizes
- understanding version control and project organization

## Notes

Each folder is designed as a small learning exercise and can be used to show how a beginner web project grows from a basic page into a more polished and design-focused webpage.
