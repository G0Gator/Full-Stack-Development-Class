# Module 2

This module focuses on JavaScript logic, problem solving, and working with APIs. The assignments in this section help students practice writing functions, handling user input, and using browser-based JavaScript with simple data-driven tasks.

## What students are learning

In this module, students practice:

- JavaScript fundamentals and logic building
- writing functions and conditional statements
- working with arrays and objects
- manipulating user input and calculations
- using an API to fetch data from a live source
- creating small interactive browser applications

## Project folders

### `Caesar's-Cipher/`
This project demonstrates a simple Caesar cipher encryption exercise using JavaScript. Students practice string manipulation and logic-based problem solving.

### `Central-Tendency-Calculator/`
This project calculates basic statistics such as mean, median, and mode. It is a good example of using JavaScript to process data and show results clearly on a page.

### `Palindrome-Checker/`
This project checks whether user input is a palindrome. It focuses on string handling and comparing values in a simple way.

### `PokeAPI/`
This project uses the PokeAPI to fetch Pokémon data and display it in the browser. It introduces students to working with an external API and processing JSON responses.

## How to use these projects

1. Open any project folder.
2. Open the `.html` file in a browser.
3. Use the JavaScript file to understand the logic behind the project.
4. If needed, test the app in the browser and inspect the console for errors.

## Module goal

The goal of Module 2 is to help students build confidence with JavaScript as a programming language and understand how it can power simple interactive features and API-based applications.
